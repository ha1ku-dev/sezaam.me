# Tag design — QR code stickers for lockboxes

## Punchline

**Il existe une alternative sans boîte à clés.**

[QR CODE → https://sezaam.me]

sezaam.me

## Tag specs

- **Size**: 5×7 cm (sticker)
- **Material**: Weather-resistant vinyl (outdoor use, UV-resistant)
- **Background**: Cream `#F2EECB`
- **Text color**: Dark green `#306230`
- **Font**: VT323 or any monospace font (matches the brand)
- **QR code**: Minimum 2.5×2.5 cm for reliable scanning
- **Layout**:
  - Top: Punchline text (2 lines)
  - Middle: QR code (centered)
  - Bottom: "sezaam.me" text (in case QR doesn't work)

## Print notes

- **Printers**: Use a label printer (Dymo, Brother P-Touch) or order from StickerMule, Vistaprint, or similar
- **Test scan**: Always test-scan the QR code before printing a batch
- **Placement**: Attach to the lockbox itself, or to the door/frame near the lockbox
- **Quantity**: Start with 20-50 for testing, then scale up
- **Durability**: Vinyl stickers last 1-2 years outdoors; paper stickers are fine for short-term
